## 5. 文档补全与执行边界

按 [初始化与文档补全.md](./初始化与文档补全.md) 填写本节时：

1. 只记录现有 CI / 脚本 / 平台入口，不新建流水线、不改生产配置、不执行部署作业。
2. 回滚与健康命令若未在本轮执行，保持 `待核实`。
3. 监控阈值、告警风暴策略若只来自外部白皮书，标 `待采纳建议`，不写进强制句。
4. 前端或后端缺失时，对应特有命令标不适用，共用 CI 仍按实际填写。
