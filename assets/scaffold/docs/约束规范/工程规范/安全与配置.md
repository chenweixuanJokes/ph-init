## 2. 凭据与脱敏

**不得入库、不得写入 Wiki / 意图 / 记忆、不得出现在通知或文档补全的联网查询里：**

- 密码、令牌、Cookie、私钥、证书材料、完整连接串
- 可直接冒用的账号口令组合
- 身份证、手机号、个人邮箱、家庭地址等个人信息

允许写的只有种类与位置，例如“生产 DB 口令在配置中心 `xxx`，本地用 `.env`（已 gitignore）”。

## 5. 配置变更

- 配置与代码的生效顺序：`<填写：先发配置还是先发代码>`。
- 默认安全：新环境默认拒绝外网和管理接口，除非文档写明已开放的端口。

## 6. 文档补全时的安全检查

初始化或文档补全过程（见 [初始化与文档补全.md](./初始化与文档补全.md)）额外遵守：

1. 只读盘点可以看配置文件名和键名，不把值复制到会话记录以外的可提交文件。
2. 公网查官方文档时不上传仓库代码、内网 URL、密钥材料。
3. 发现已入库秘密：停止相关文档写入，报告路径与键名（不回显值），等待用户处理。
4. 不实际切换生产配置、不调用会改变权限或密钥的管理接口。
