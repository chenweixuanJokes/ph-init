# <访谈主题>

一次会话一份纪要，内部按轮次追加。`purpose` 为 `capture` / `plan` / `abandon`；`status` 为 `ongoing` / `complete` / `paused`。`intent_id` 指向目标意图的稳定编号，意图通过 `interviews` 引用本文件；意图移动时纪要留在原目录。`related` 中的路径相对仓库根。

规则见 [意图与访谈](../../约束规范/工程规范/意图与访谈.md)。旧答案不覆盖，纠正时追加记录；原话与转述明确区分，敏感信息省略并标明已脱敏，不保存模型内部思考。

## 访谈目的与关联

本次要解决的缺口、目标意图编号及已存在的文件链接。意图类型尚未确定、文件未建立时如实标注待建立引用，后续建立草稿时补齐，不伪造链接。

## 问前调研与复用依据

列出与本次决策有关的资料/代码位置、已核实事实、已明确的用户决定及证据限制。无新增问题时写明原因与复用来源，不虚构轮次。
