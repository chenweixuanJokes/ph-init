# 1.0.0 → 1.1.0

历史补录，不是新发布。仓库当时没有 tag；`1.1.0` 只出现在 manifest / Schema 锁里。正式对外 tag 从 [1.1.1](./1.1.0-to-1.1.1.md) 开始。

## why

在六 Skill 安装包上补齐意图域：访谈式录入、原生计划模式交接、原因明确的废弃。同时把 `schema_version` / `template_version` 锁到 `1.1.0`，必需 Skill 变成九个。

## from

按文件实态识别，不能只看口中的“1.0”：

- `.agents/ph.json` 的 `schema_version` 与 `template_version` 为 `1.0.0`。
- 六个必需 Skill：`ph-init`、`ph-worktree-enter`、`ph-worktree-exit`、`ph-memory-capture`、`ph-memory-archive`、`ph-memory-ask`。没有意图 Skill。
- 意图目录是 `docs/意图/进行中/{新特性,问题记录}/`、`访谈纪要/`、`已完成/`、`已废弃/`。
- 文档治理把“进行中”当现行状态；尚无 `docs/约束规范/工程规范/意图与访谈.md`。
- `init` / `check` / `sync` 只做安装与适配层，不是升级器。

## to

- 九个必需 Skill，意图三个当时名为 `ph-intent-capture` / `ph-intent-plan` / `ph-intent-abandon`。
- 新增意图模板字段、纪要模板、`意图与访谈.md`；`AGENTS.md` 与相关 README 增加意图 Skill 入口。
- 版本锁变为 `1.1.0`。意图生命周期目录**仍是** `进行中/`，本段不改成待办/实施。
- 本段完成后的项目仍可能停在旧意图名；那是下一跳 [1.1.0 → 1.1.1](./1.1.0-to-1.1.1.md) 的 `intent-skill-names`。

## affected

- `.agents/ph.json` 的版本锁与 `skills.required_names`（收尾时才写版本）。
- 新增 `.agents/skills/ph-intent-capture|plan|abandon/` 及厂商适配入口。
- `.agents/AGENTS.md` 的 Skill 表；`docs/意图/_模板.md`、`docs/意图/访谈纪要/_模板.md`、`docs/意图/README.md`。
- 新增 `docs/约束规范/工程规范/意图与访谈.md`，以及工程规范 README 索引。
- 项目内自包含 `ph-init` 分发包（从目标发行版复制，保留项目定制）。

不改业务意图正文、不搬 `进行中/` 条目、不改 adapter mode。

## preserve

- 已有 `进行中/` 业务文件、编号、访谈原话、历史代码块。
- 用户写进 AGENTS / 规范 / Wiki / 记忆的项目事实。
- portable / symlink 选择。
- 六 Skill 的本地定制；只叠加三个意图 Skill，不整目录覆盖。

## conflict

- 目标路径已有不同内容的意图 Skill 或规范：先备份到受控目录或 `~/trash/`，不 `rm`，该项 `blocked`。
- 根 `AGENTS.md` 在而 `.agents/AGENTS.md` 不在：迁移阻断，不自动合并。
- 无法判断是否 1.0.0 六 Skill 布局：停止，不按最新模板猜历史。
- 与项目显式规则冲突：停止受影响项，请用户决定。

## verify

- 三个意图 Skill 目录存在，`name` 与目录一致；厂商入口按原 adapter mode 可同步。
- `意图与访谈.md` 与纪要/意图模板可从仓库根相对路径打开。
- `进行中/` 业务条目仍在原处，编号与纪要引用未改写。
- 本项 `intent-domain` 在 state 中为 `applied` 或 `not_applicable`（项目当时已有等价意图域）。
- 未跑 candidate check 前不改磁盘 `template_version`。
